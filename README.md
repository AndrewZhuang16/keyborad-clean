# 键盘清理 (KeyboardClean)

一个 macOS 小工具：打开应用有一个开关，打开后键盘失效（方便擦拭清洁键盘），
可以手动关闭，也可以在退出应用时自动恢复键盘输入。

## 功能

- **一键开关**：打开「清理模式」开关后，键盘输入被全局拦截（鼠标不受影响）。
- **手动关闭**：随时用鼠标关闭开关即可恢复键盘。
- **退出自动恢复**：关闭窗口 / 退出应用时自动恢复键盘；即使应用崩溃或强制退出，
  事件拦截也会随进程结束被系统自动拆除，不会出现键盘永久失灵。
- **权限引导**：首次使用会引导你授予「辅助功能」权限，并可直接跳转系统设置。

## 原理

使用 macOS 的 `CGEvent` 事件拦截（event tap）在会话事件流头部放置一个 active tap，
把 `keyDown` / `keyUp` / `flagsChanged` 事件丢弃（回调返回 `nil`），从而让键盘
系统级失效。active event tap 需要「辅助功能 (Accessibility)」权限。

## 构建

需要 macOS 与 Xcode 命令行工具（`swift` 可用即可，无需完整 Xcode）：

```bash
./build.sh
```

构建产物在 `dist/键盘清理.app`，双击运行即可。

> 注意：`build.sh` 使用 ad-hoc 签名。系统对「辅助功能」权限的识别绑定到二进制
> 的代码签名；重新构建后如果二进制发生变化，可能需要重新授权一次。

## 使用

1. 双击打开 `键盘清理.app`。
2. 打开「清理模式」开关；首次会弹出系统授权提示，点击「打开系统设置」→
   在「隐私与安全性 → 辅助功能」中勾选本应用。
3. 授权后重新打开开关，键盘即失效，可以开始清洁。
4. 清洁完毕关闭开关，或直接退出应用，键盘立即恢复。

## 常见问题（权限）

- **授权后应用仍提示需要权限**：macOS 常常需要重启应用才能识别新授权的权限。
  点击界面上的「重新启动应用」即可。
- **重新构建/替换应用后授权失效**：`build.sh` 使用 ad-hoc 签名，系统对「辅助功能」
  权限的识别绑定到二进制签名（每次构建可能变化）。如果重新构建或替换了 `.app`，
  需要到「系统设置 → 隐私与安全性 → 辅助功能」里删除旧的条目并重新勾选一次。
- **在列表中勾选的是哪个应用**：界面会显示本应用的 `Bundle ID`
  （`com.keyboardclean.app`），可在辅助功能列表里核对。
- **列表里已勾选但仍提示需要权限（最常见）**：这是授权对应了旧版本构建。
  因为应用是 ad-hoc 签名，每次重新构建签名都会变，旧授权就失效了。解决办法：
  1. 在「辅助功能」列表里选中旧的「键盘清理」条目，点下方「-」号删除；
  2. 重新打开应用、打开开关，按系统提示重新勾选本应用；
  3. 仍不识别就点界面上的「重新启动应用」。
  之后只要**不重新构建/替换** `.app`，授权会一直有效。

## 目录结构

- `Sources/KeyboardClean/KeyboardCleaner.swift` — 事件拦截与权限逻辑
- `Sources/KeyboardClean/ContentView.swift` — SwiftUI 界面
- `Sources/KeyboardClean/KeyboardCleanApp.swift` — 应用入口与退出恢复
- `Resources/AppIcon.icns` — 应用图标
- `scripts/render_icon.swift` — 用 CoreGraphics 绘制 1024x1024 图标
- `scripts/make_icon.sh` — 生成多尺寸 `AppIcon.icns`
- `build.sh` — 编译并打包为 `.app`（图标不存在时自动生成）
